# Contributing to Local webOS TV Controller

Thank you for helping improve this independently maintained Homey Pro app.

Before opening an issue, search for an existing report and confirm that the
problem belongs to Local webOS TV Controller rather than the television, Homey itself,
or an external ARC/eARC audio system. Include the television model, webOS
version, Homey model, app version, active sound output and the exact device
control or Flow card involved.

Pull requests should be focused on one issue, retain upstream attribution and
the GPL-3.0-or-later licence, preserve existing device and Flow identifiers,
and include regression coverage. Run the complete test command and both Homey
publish and verified validation levels before requesting review.

Do not include LG pairing keys, Homey credentials, private IP addresses,
diagnostic archives containing personal information or copyrighted media.

This project is community maintained and is not affiliated with or endorsed by
LG Electronics, Athom B.V. or the original WebOS Plus maintainer.
